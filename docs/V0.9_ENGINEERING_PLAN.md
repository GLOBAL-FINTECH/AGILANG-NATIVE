# AGILANG Native v0.9 engineering plan

The v0.9 track is split into ten independently testable production surfaces.

1. Generics — generic type parameters, generic functions, monomorphization and type-constraint diagnostics.
2. Closures — closure AST/HIR, capture analysis, environment lowering and native invocation.
3. Result/error model — Result/Option types, propagation syntax and structured runtime errors.
4. Ownership/lifetimes — immutable-binding enforcement, move/copy rules and lifetime diagnostics.
5. Module resolver — canonical module paths, dependency graph, cycle detection and deterministic resolution.
6. Formatter — agilang-fmt with check mode for CI.
7. Package ecosystem — registry/cache abstraction, source checksums and offline lock verification.
8. Debugger — Debug Adapter Protocol foundation for launch, breakpoints, stack frames and evaluation.
9. Standard library — stabilized APIs for filesystem, networking, HTTP/HTTPS, JSON, crypto, processes and concurrency.
10. Distribution — standalone compiler bundle, Linux/Windows/macOS installers, checksums, signing and provenance.

The first v0.9 commit adds the ownership-validation library, formatter, debugger protocol foundation and release architecture. Existing compiler/runtime capabilities remain the source of truth; no feature is declared complete until parser -> semantic -> codegen -> native execution tests exist.
