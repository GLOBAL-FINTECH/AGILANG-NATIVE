# One-to-One Compatibility Contract

The normative compatibility requirements are maintained in the repository root [`README.md`](../README.md), especially Sections 2–15.

This file exists as a stable documentation target for tooling, pull requests, and release reviews.

A feature is compatible only when its `compat/feature-matrix.csv` row reaches `release-compatible` and the canonical commit in `compat/canonical.lock.json` is a real 40-character Git commit SHA.
