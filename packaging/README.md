# AGILANG Native distribution

Release artifacts contain:
- bin/agilang / agilang.exe
- lib/libagilang_runtime_abi.a and the platform dynamic runtime
- runtime/runtime-manifest.json
- toolchain.json
- SHA-256 checksums
- a detached release signature

Tagged releases are built on Linux, Windows and macOS. Project dependency state is recorded by agilang.toml and agilang.lock.
